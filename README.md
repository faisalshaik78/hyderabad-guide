# Hyderabad Guide

A simple Hyderabad city guide landing page with an accessible navigation menu, responsive layout, and polished styling.

## Features
- Clean hero section and city highlights
- Responsive navigation menu
- Mobile-friendly layout
- Modern typography and color palette

## Run locally
Open `index.html` in a browser, or serve with:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
