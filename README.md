# Hyderabad Guide

A responsive city-guide website that introduces Hyderabad through its landmarks, local food, and transport options. Built with semantic HTML, CSS, and vanilla JavaScript.

## Overview

Hyderabad Guide is a lightweight front-end project designed to make city information easy to browse. It features a clear navigation menu, a simple page structure, and layouts that adapt to desktop and mobile screens.

## Features

- **Responsive navigation** — desktop menu with a mobile toggle.
- **Explore landmarks** — quick introductions to Charminar, Golconda Fort, and Hussain Sagar.
- **Local food guide** — highlights popular Hyderabadi dishes and drinks.
- **Transport information** — an overview of metro rail, city buses, autos, and cabs.
- **Accessible interactions** — skip link, visible keyboard focus, Escape-to-close menu support, and reduced-motion preference.
- **Responsive layout** — flexible card grids and typography for different screen sizes.

## Run Locally

No build tools or dependencies are required.

1. Clone the repository:

   ```bash
   git clone https://github.com/faisalshaik78/hyderabad-guide.git
   ```

2. Open the project folder:

   ```bash
   cd hyderabad-guide
   ```

3. Start a local server:

   ```bash
   python -m http.server 8000
   ```

4. Open [http://localhost:8000](http://localhost:8000) in your browser.

You can also open `index.html` directly in a browser.
